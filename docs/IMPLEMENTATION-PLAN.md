# Implementation Plan

This repository is a starter milestone, not the completed FYP.

1. Frontend dashboard and local API (implemented as demo).
2. Automated tests and persistent incident/recovery storage.
3. Dockerfiles and Docker Compose.
4. Kubernetes manifests and Helm chart.
5. Python Kubernetes client with read-only context collection.
6. Prometheus metrics, Grafana dashboard, and Loki log collection.
7. Policy engine with auditable allowlisted recovery actions.
8. Optional AI/LLM incident analysis; model suggestions must not execute actions directly.
9. GitHub Actions build/test pipeline.
10. Terraform-managed AWS environment and Argo CD GitOps.
11. Controlled failure testing and measurements for detection/recovery time.
